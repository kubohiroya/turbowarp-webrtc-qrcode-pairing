TurboWarp-WebRTC-QRCode-Pairing

Initial TurboWarp extension scaffold for QR-carried WebRTC Offer and Answer pairing. Pairing is not implemented yet.

The current hello [NAME] reporter verifies extension loading only.

The planned workflow displays an Offer on the integration machine, scans it on a camera machine, carries the Answer QR images back using a smartphone, and confirms a WebRTC connection.
